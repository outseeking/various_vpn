# Как поставить приложение на iPhone, имея только Windows

Коротко: **компилирует облачный Mac, ставит ваш компьютер.** Собственный Mac не
нужен, но и обойтись совсем без macOS нельзя — Apple разрешает сборку iOS-
приложений только на своей системе.

---

## Что происходит

1. GitHub бесплатно выдаёт публичным репозиториям машины с macOS.
2. Там собирается `.ipa` — **без подписи**: ваши сертификаты в облако не
   уезжают вовсе.
3. Готовый файл скачивается на компьютер.
4. Программа-установщик подписывает его вашей учётной записью Apple прямо на
   Windows и заливает на телефон по кабелю.

---

## Шаг 1. Собрать .ipa

Репозиторий должен лежать на GitHub. Дальше — вкладка **Actions** → слева
**«Сборка iOS»** → кнопка **Run workflow**.

Через 10–15 минут внизу страницы появится архив **various-vpn-ipa**. Скачайте и
распакуйте — внутри `various-vpn.ipa`.

Можно и без кнопки: сборка запускается сама на теге вида `v1.0.0`.

## Шаг 2. Поставить на телефон

Нужен **кабель** и **Apple ID** (подойдёт обычный, бесплатный).

**Sideloadly** — `sideloadly.io`, проще всего:

1. Установите на Windows, подключите iPhone кабелем.
2. Перетащите `.ipa` в окно, введите Apple ID.
3. Нажмите Start. Через пару минут значок появится на телефоне.
4. На телефоне: **Настройки → Основные → VPN и управление устройством** →
   ваш профиль → **Доверять**.

**AltStore** (`altstore.io`) делает то же самое, но умеет продлевать срок сам,
пока телефон в одной сети с компьютером.

---

## О чём предупредить заранее

**Срок жизни — 7 дней.** С бесплатным Apple ID подпись действует неделю, потом
приложение перестаёт открываться. Лечится повторной установкой (или AltStore
делает это сам). Платный аккаунт разработчика — 99 $ в год — поднимает срок до
года.

**Три приложения.** Больше трёх программ, поставленных таким способом,
бесплатный аккаунт одновременно держать не даёт.

**VPN сразу не заработает.** Расширению нужны две нативные библиотеки —
`libXray.xcframework` и tun2socks, — которых в репозитории пока нет: они
собираются из Go и C. Без них приложение запустится и покажет весь интерфейс,
но туннель не поднимется. Подробности — в `README_iOS.md`, раздел 2.

То есть этим путём вы сегодня получаете **рабочее приложение без туннеля** —
посмотреть, потрогать, показать. Полноценный VPN включится, когда в проект
добавят те две библиотеки.
