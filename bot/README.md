# Юридический раздел бота — что положить на сервер

Исходники бота лежат только на сервере, поэтому здесь готовые файлы: скопировать
и подключить тремя строками.

## Что копировать

```
bot/legal.py        → рядом с основным файлом бота
bot/legal/*.md      → каталог legal/ рядом с legal.py (6 документов)
```

## Подключение

В основном файле бота:

```python
from legal import legal_router, LEGAL_BUTTON

dp.include_router(legal_router)
```

`legal_router` подключай **после** своего основного роутера: тогда твой
обработчик `legal:back` (возврат в меню поддержки) сработает раньше запасного
из модуля.

## Что поменять в разделе «Поддержка»

Убрать кнопку «Пользовательское соглашение» и поставить на её место
`LEGAL_BUTTON` — она ведёт в список из шести документов:

```python
support_kb = InlineKeyboardMarkup(inline_keyboard=[
    [InlineKeyboardButton(text="✍️ Написать в поддержку", callback_data="sup:write")],
    [LEGAL_BUTTON],                     # ⚖️ Юридическая информация
    [InlineKeyboardButton(text="🔴 Назад", callback_data="menu")],
])
```

Соглашение никуда не делось — оно второй пункт внутри юридического раздела.
Отдельной кнопкой оно закрывало собой остальные пять документов.

## Возврат из раздела

Кнопка «Назад» в юридическом разделе шлёт `legal:back`. Обработай её у себя —
она должна открывать меню поддержки:

```python
@router.callback_query(F.data == "legal:back")
async def back_to_support(cb: CallbackQuery):
    await cb.message.edit_text(SUPPORT_TEXT, reply_markup=support_kb)
    await cb.answer()
```

Про красный цвет: в Telegram цвет inline-кнопки задать нельзя, его несёт эмодзи.
`🔴 Назад` — тот же приём, что и в остальном меню сервиса.

## Ссылка из приложения

В приложении раздел «Юридическая информация» открывается ссылкой
`t.me/variousvpnbot?start=legal`. Обработчик deep-link уже внутри `legal.py`,
делать ничего не нужно.

## Перед публикацией — заполнить плейсхолдеры

Во всех шести файлах есть заготовки, которые обязаны быть заполнены до приёма
платежей:

| Плейсхолдер | Что подставить |
|---|---|
| `{ДАТА}` | дата редакции документа |
| `{ПОЛНОЕ НАИМЕНОВАНИЕ / ФИО}` | как в ЕГРИП/ЕГРЮЛ |
| `{ИНН}` | ИНН |
| `{ОГРНИП}` | ОГРНИП (или ОГРН) |
| `{EMAIL}` | почта для юридически значимых обращений |
| `{АДРЕС}` | адрес для корреспонденции |

Тексты правятся прямо в `.md` — модуль читает файл на каждый показ,
перезапускать бота не нужно.
